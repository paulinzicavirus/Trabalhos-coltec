# Xwitter — COLTEC

Projeto de rede social em Node.js/Express, EJS, Sequelize/SQLite, Bootstrap, D3.js e p5.js.

## Execução planejada
Node 24, `npm install`, configuração de `.env`, `npm run seed`, `npm start`; testes por Playwright e MCP locais.

## Situação
O relatório em PDF foi preparado separadamente. O ambiente não permitiu instalar dependências nem executar MCP; portanto não há comprovação de execução e teste do projeto. Os códigos locais não devem ser considerados publicados no GitHub até a sincronização integral.
